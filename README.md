# React E-Commerce Website

This project is a simple and modern e-commerce web application built using **React JS**.  
The application consumes data from **FakeStoreAPI** to display products dynamically.

## 🚀 Features
- Product listing
- Product details page
- Categories filtering
- Shopping cart functionality
- Responsive UI
- API integration using FakeStoreAPI

## 🛠️ Technologies Used
- React JS
- JavaScript (ES6)
- CSS
- FakeStoreAPI
- React Router

## 🌐 API Used
FakeStoreAPI  
https://fakestoreapi.com/
